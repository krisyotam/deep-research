DEEP RESEARCH

Research tool for generating comprehensive, source-backed reports
from web searches. Builds structured documents with citations,
stored in a SQLite database.


STRUCTURE

  sources.db          Source material database
  prompts.db          Research prompt history
  content/            Research reports (markdown), formerly the deep-research-texts / reports submodule
  pages/              Page templates
  static/             Static assets
  dist/               Build output
  build.js            Build script
  init-db.js          Database initialization
  extract-sources.js  Source extraction utilities
  import-gdrive.js    Google Drive import
